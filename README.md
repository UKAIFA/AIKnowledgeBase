# UKAIFA AI Knowledge Base

The UK AI factory antenna, [UKAIFA](https://pilot-ukaifa.ai/), is the UK element of the EuroHPC JU AI factory program, delivered by [EPCC](https://www.epcc.ed.ac.uk) the UK national supercomputing centre at [the University of Edinburgh](https://www.ed.ac.uk).

UKAIFA is partnered with the [HammerAI](https://www.hammerhai.eu/) AI Factory consortia in Germany we aim to support industry and the public dedtor to build, test and scle AI solutions.

This repository contains the AI Knowledge base of the UKAI factory antenna and is linked to a rendered version currently hosted on Github.
