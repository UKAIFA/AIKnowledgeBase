# Workflows

There are a wide variety of workflows that can be created to train, transform, serve and use AI models, in this documentation we provide a number of examples of different workflows and examples of how to get them running within the EIDF.

The classes of workflows include:

## Basic Software execution in kubeneties
  - Setup
  - Containers
  - Kubeneties Code Execution workflow
  - Kubeneties Developer workflow
  - Kubeneties Profiling workflow

## Training
  - Supervised learning
  - Unsupervised learning
  - Reinforcement learning
  - Agent supervised learning
  - Federated learning

## Transformations
  - Specialisation
  - Distillation
  - Emulation

## Inference
  - Running inference servers
  - Advanced inference methods
  - Inference services
  - Dedicated Inference
  - Privacy in Inference

## Agentic workflows
  - Tools
  - MCPs

## User Environments
  - Integrations
  - Sandboxes
  - Skills
  - Multi-agent environments
