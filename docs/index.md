# UKAIFA AI Knowledge Base

The UK AI factory antenna, [UKAIFA](https://pilot-ukaifa.ai/), is the UK element of the EuroHPC JU AI factory program, delivered by [EPCC](https://www.epcc.ed.ac.uk) the UK national supercomputing centre at [the University of Edinburgh](https://www.ed.ac.uk).

UKAIFA is partnered with the [HammerAI](https://www.hammerhai.eu/) AI Factory consortia in Germany we aim to support industry and the public dedtor to build, test and scle AI solutions.

This repository contains the AI Knowledge base of the UKAI factory antenna and is linked to a rendered version currently hosted on Github.

## What this documentation covers

This documentation covers the workflows and approaches for using AI tools and devleoping AI workflows with concrete examples of implementing these workflows in the [EIDF](https://www.ed.ac.uk/edinburgh-international-data-facility/) hosted at EPCC and workflows integrating with [HAMMERAI](https://www.hammerhai.eu/) services.

## Contributing to the documentation

The source for this documentation is publicly available in the [UKAIFA AI Knowledge Base Github repository](https://github.com/UKAIFA/AIKnowledgeBase) so that anyone
can contribute to improve the knowledgebase.

Contributions can be in the form of improvements or additions to the
content and/or addition of Issues providing suggestions for how it can be
improved.

Full details of how to contribute can be found in the [`README.md`](https://github.com/UKAIFA/AIKnowledgeBase/blob/main/README.md) file of the repository.
